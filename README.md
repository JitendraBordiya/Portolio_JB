# Jitendra Bordiya — Portfolio

Single-page portfolio website for Jitendra Bordiya, Full Stack Engineer (MERN & .NET Core), Pune, India.

**Live site:** https://jitendrabordiya.github.io/Portolio_JB/

## Features
- Light and dark mode (remembers your choice)
- Responsive layout with mobile menu
- Project cards with filters and detail pop-ups
- Skills, achievements and contact sections with copy-to-clipboard
- Plain HTML, CSS and JavaScript. No build step, no dependencies.

## Run locally
Open `index.html` in any browser.
